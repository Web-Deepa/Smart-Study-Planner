# 📚 Smart Study Planner

A comprehensive digital companion designed to revolutionize the way you plan, study, and track academic growth. This platform transforms chaotic study habits into structured, data-driven daily routines.

## ✨ Core Features

*   **📅 Digital Planning:** Easily schedule your subjects, topics, and deadlines with an intuitive, interactive interface built for modern students.
*   **📈 Progress Tracking:** Visualize your learning journey with detailed analytics that showcase your study patterns, completed topics, and areas needing focus.
*   **⏰ Smart Notifications:** Never miss a session. Get automated notifications detailing exactly what you need to study based on the specific plan of the day.

## 🚀 Key Modules Included

*   **Daily Agenda Dashboard:** A clean overview of your priority tasks every time you log in.
*   **Subject Metrics:** Track the completion percentage of each syllabus module.
*   **Timers & Focus Blocks:** Deep-work integration to help minimize distractions.

## 🛠️ Built With

*   **Frontend:** HTML5, CSS3, JavaScript ,Bootstrap 5
*   **Backend:** Python / Flask 
*   **Database:** Sqlite
